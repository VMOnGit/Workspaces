# Verilog.ws

This directory contains Verilog-related workspace files for digital design and hardware description. It is part of the [Workspaces](https://github.com/VMOnGit/Workspaces) repository.

## Folder Structure

```
Verilog.ws/
├── .gitignore
├── LED_Peripheral/
├── LED_ROM/
├── Light_Controller/
└── Synchronous_FIFO/
```

## Contents

- **LED_Peripheral/**: Example modules and logic for LED control peripherals.
- **LED_ROM/**: Sample ROM components or LED ROM interface designs.
- **Light_Controller/**: Verilog modules for light/LED controller logic and testbenches.
- **Synchronous_FIFO/**: FIFO buffer implementations and associated testbenches.

## Getting Started

1. **Browse the directories** for module, peripheral, ROM, controller, and FIFO code.
2. **Open in your IDE** (such as VS Code) or use online tools for Verilog simulation.
3. **Run simulations and extend**: Use tools like Icarus Verilog, ModelSim, Vivado to compile and verify.
4. **Contribute** your own modules or enhancements—pull requests are welcome!
